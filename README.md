# 🏫 School Management System (Écolee)

A desktop application for managing school administration, students, teachers, courses, grades, and user authentication. Built with Java Swing and MySQL following the Data Access Object (DAO) architecture pattern.

---

## 📸 Key Features

- 🔐 **Authentication & Role Management**: Secure login system for admins, teachers, and students.
- 👨‍🎓 **Student Management**: Full CRUD operations for managing student profiles, enrollment, and class assignments.
- 👨‍🏫 **Teacher & Subject Tracking**: Assign teachers to specific courses, majors/tracks, and schedules.
- 📊 **Grades & Evaluation**: Input, update, and compute student performance and transcripts.
- 🗃️ **Modular Architecture**: Clean separation of database logic (DAO layer) and graphical interface (Swing/AWT).

---

## 🛠️ Tech Stack & Prerequisites

* **Language**: Java SE 8+
* **GUI Framework**: Java Swing / AWT
* **Database**: MySQL 8.0+
* **IDE**: NetBeans IDE (recommended)
* **Database Connectivity**: JDBC (MySQL Connector/J)
